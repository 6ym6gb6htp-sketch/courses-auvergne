 # Courses Auvergne 🏃‍♂️

Problème : impossible de trouver les petites courses autour de Clermont.
Solution : Site pour trouver toutes les courses a pied en auvergne -des petites foulées de village aux trails. Filtres par distance, date et autour de moi

### MVP - Phase 1
- [x] Carte avec filtre "autour de moi"
- [ ] Filtres : distance (5k/10k/semi), type (route/trail), date
- [ ] Fiche course : parcours, prix, lien inscription

### Stack
Next.js + Supabase + Mapbox

### Roadmap
Phase 2 -> Connect Strava et analyse à la Runalyze
Phase 3 -> Alertes "nouvelle course près de chez toi"

### Comment contribuer
Les organisateurs peuvent ajouter leur course via /data/courses.json
